# กรอบไอคอนภาษาไทย

ดาวน์โหลด [frame.png](frame.png): PNG RGBA ขนาด 1254 × 1254 พิกเซล

กรอบเตรียมโดยอิงกรอบด้านนอกของ [ไอคอนของม็อด](../../ThaiOfflineAllMods/icon_workshop.png)
ต้นฉบับที่มีเป็น PNG รวมภาพ จึงเตรียมกรอบแยกขึ้นมาโดยรักษารูปแบบเดิม
ตรงกลางและพื้นที่นอกกรอบเป็นพื้นหลังโปร่งใส ไม่มีตัวอักษร ธง หรือป้ายไม้ติดมาด้วย

นำกรอบไปวางเป็น layer บนภาพของตัวเองได้ใน GIMP, Krita หรือโปรแกรมแต่งภาพที่รองรับ PNG
ถ้าปรับขนาด แนะนำ nearest neighbor เพื่อรักษาขอบแบบพิกเซล
